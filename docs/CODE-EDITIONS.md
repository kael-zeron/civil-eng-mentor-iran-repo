# وضعیت ویرایش آئین‌نامه‌ها
| آئین‌نامه | وضعیت |
|---|---|
| مبحث ۹ | ویرایش ۱۳۹۹ (پنجم) تأیید شد |
| استاندارد ۲۸۰۰ | ویرایش پنجم منتشر شده (به گفته کاربر)؛ شماره بندها و مقادیر باید از متن رسمی بیاید |
| مبحث ۱۰ | تأیید نشده |
| مبحث ۶، ۷ | تأیید نشده |
قاعده: مقدار قدیمی به‌عنوان مقدار فعلی ارائه نشود. پیش از انتشار، با متن رسمی بررسی شود.
